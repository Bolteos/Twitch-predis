Lleva bolteos-perks a tu stream

Elige el mazo y los ajustes. Copia el enlace a OBS. Cada vez que se cargue la fuente, repartirá cuatro cartas.

Para conectar OBS y Stream Deck en Windows, descarga el conector del directo, extrae el ZIP y abre Iniciar directo.bat en el PC del stream. Se abrirá el panel conectado. Cierra la ventana del conector al terminar. Requiere Python 3.

01 / OBS Studio

Crea una fuente Navegador de 1920 × 1080 y pega este enlace.

Repartir con una tecla

En OBS, abre Ajustes → Atajos. Busca tu fuente Navegador y asigna una tecla a «Actualizar caché de la página actual». En Stream Deck, usa Sistema → Atajo con la misma combinación.

02 / Stream Deck

Usa la acción Sistema → Sitio web. Cada apertura activa un reparto.

Sonido y ajustes del reparto

La fuente reparte al abrirse y cada vez que la actualizas. Si cambias el mazo, la duración o el volumen en este panel, vuelve a copiar el enlace en OBS. Para gestionar el sonido desde el mezclador, activa «Controlar audio a través de OBS» en la fuente.

Instrucciones de conexión y sonido
  1. En OBS: Fuentes → + → Navegador. Nombre: bolteos-perks. Pega el enlace OBS, usa las dimensiones que elegiste en el panel (Full HD o 4K).
  2. Activa «Controlar audio a través de OBS». En Propiedades avanzadas de audio, deja la fuente en «Monitorización desactivada» para enviarla al directo; usa «Monitorización y salida» si también quieres escucharla.
  3. Desactiva «Cerrar fuente cuando no sea visible» y «Actualizar navegador cuando la escena se active» para mantener la conexión.
  4. En Stream Deck: arrastra Sistema → Sitio web a una tecla. Pega el enlace de activación. Si aparece «GET en segundo plano», actívalo; si no, se abrirá una pestaña con la confirmación.
  5. Prueba con «Barajar y repartir». El overlay queda invisible en reposo. No necesitas dejar este panel abierto para usar Stream Deck.

Los enlaces incluyen la clave de tu canal. Conserva ambos enlaces para reutilizar el mismo mazo. Si el sonido no se oye, en OBS pulsa «Interactuar» sobre la fuente y haz un clic para habilitar audio. La integración externa necesita acceso al sitio sin inicio de sesión.
